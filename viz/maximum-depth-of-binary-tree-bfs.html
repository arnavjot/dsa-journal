Maximum Depth by counting levels (BFS)

Go level by level with a queue. Each pass of the outer loop takes exactly the nodes that are in the queue right now (size): one whole level. Count the passes; that count is the depth.

Why size first: children pushed during the loop belong to the next level. Freezing the size keeps one pass = one level.
