Add Two Numbers, step by step

The digits are stored backwards, so the first node is the ones digit. That's exactly the order you add by hand: start at the ones column, carry into the next. Each column below is one place value. Read a list right to left to get its number.

Why the carry is only ever 0 or 1: the biggest a column can be is 9 + 9 + 1 = 19, so sum / 10 is at most 1.

  
Why the loop also checks carry != 0: when both lists run out with a carry left (999 + 1), one more node is needed for that last 1. Try "Carry at the very end" or Example 3.

  
Why the dummy node: temp->next = new ListNode(...) works the same for the first digit as for every other one, so there's no "is the answer still empty?" special case. Return dummy->next to skip it.
