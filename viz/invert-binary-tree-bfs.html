Invert Binary Tree with a queue (BFS)

Same one job per node, swap its two children, but the nodes are visited level by level from a queue instead of by recursion. Pop a node, swap, push its (new) children. When the queue is empty, every node has swapped, so the tree is mirrored.

Why order doesn't matter: each node only swaps its own two children, so any visiting order (recursion, queue, stack) mirrors the tree.

  
Same time: O(n), each node popped once. The queue holds up to a whole level, O(w), instead of the O(h) call stack.
