Invert Binary Tree, step by step

Inverting = mirroring the tree left ↔ right. At every node do one tiny job: swap its two children. Then ask the recursion to do the same job inside each child. When every node has swapped its children, the whole tree is mirrored.

Why temp: after root->left = root->right, the old left child would be lost. temp keeps it so it can become the new right child. Same idea as swapping two variables.

  
Why it works: mirroring a tree = swap the two subtrees and mirror each of them. The recursion trusts that invertTree(child) mirrors that child completely.

  
The NULL check: a leaf's children are NULL, so those calls return straight away. That's the base case that stops the recursion.
