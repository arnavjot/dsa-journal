Why it must match all the way down: a subtree is a node and all its descendants. Try "Extra node below": the 2 matches, but root's 2 has a child that subRoot's 2 doesn't.
Cost: isSameTree can run from every node of root, so it's O(m × n) in the worst case (m, n = sizes of the two trees).
Faster idea: serialize both trees (with null markers) and look for subRoot's string inside root's with KMP: O(m + n).
