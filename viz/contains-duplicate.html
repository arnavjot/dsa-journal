Why check before inserting: if you inserted first, count() would always find the number you just put in, and every array would look like it has a duplicate.

  
Why it can stop early: one repeat is enough to answer true, so return true happens the moment it's found. Only an array with no repeats is read to the end.

  
About the buckets: this picture uses a fixed 7 buckets (bucket = number mod 7) so it stays small. A real unordered_set adds more buckets as it fills up, which keeps every bucket short. A bucket holding different numbers is normal (1 and 8 both land in bucket 1): count() compares only the few numbers in that one bucket.
