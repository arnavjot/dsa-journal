Design Add and Search Words, step by step

addWord is a normal trie insert. search is a DFS over the word's letters: a letter follows its one link; a '.' can be any letter, so it tries every existing child in turn and returns true as soon as one of them leads to a full match. At the end of the word, the node's flag decides.

Why DFS for '.': a dot can match any child, so the search branches. Recursion tries one branch fully, and if it fails, backs up and tries the next.
Why return true right away: one full match is enough; the other branches are skipped.
Cost: addWord O(L). search O(L) with no dots; each dot can multiply the branches (worst case up to 26 per dot), but LeetCode allows at most 2 dots.
