Largest Rectangle, two passes, step by step

Bar i at full height can stretch until the first shorter bar on each side. Pass 1 finds the previous smaller index for every bar (left → right), pass 2 the next smaller (right → left). Then width = next − prev − 1 and area = height × width.

Why the −1 sentinel: it sits at the bottom of the stack and means "nothing smaller on this side". In pass 1, prev = −1 makes the width start at index 0. In pass 2, the code turns −1 into n, so the width runs to the last bar.

  
Why >= when popping: equal bars are popped too, so "previous smaller" means strictly smaller. That's what lets a bar stretch across equal neighbours: try "Equal: [3,3,3]".

  
One pass vs two: the one-pass version finds the same two limits at the moment a bar is popped. Two passes are easier to reason about, but need two extra arrays.
